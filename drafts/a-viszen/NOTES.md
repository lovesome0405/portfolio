# 시안 A — "네 개의 장" (참고: viszen.tech)

열기: 저장소 루트에서 정적 서버를 띄우고 `/drafts/a-viszen/`을 연다 (예: `python3 -m http.server` → `http://localhost:8000/drafts/a-viszen/`). 파일로 바로 열어도 동작한다.
파일: `index.html`, `a.css`, `a.js`(바닐라 JS, 외부 스크립트 없음), `shots/`(캡처). 기존 `index.html`, `style.css`, `assets/`는 건드리지 않았다.

## ① 참고 사이트에서 가져온 원리

| 가져온 것 | 이 시안에서 바꾼 방식 |
|---|---|
| 한 화면 = 한 장면(100vh 패널), 섹션마다 배경 색조가 바뀜 | 장(프로젝트)마다 어두운 색조 1개. 스크롤로 장이 바뀌면 배경이 0.9초에 걸쳐 바뀜 |
| 점(파티클) 형체가 스크롤에 따라 다른 모양으로 바뀜 | Three.js 3D 모델 대신 2D 캔버스 점 1,100개(모바일 560개)가 장마다 그 프로젝트를 상징하는 선 그림으로 모임: 고리 → AI → 방패(피싱 확인) → 큐브(3D 가구) → 휴대폰(학생 앱) → 지붕과 기둥(전통문화) → 흩어짐(숫자) → 끝이 열린 원(다음 장) |
| 큰 압축 대문자 제목 + 짧은 부제 한 줄 + 3줄 목록, 데스크톱에선 오른쪽 정렬 | 같은 리듬. 3줄은 "무엇을 / 역할·팀 / 결과"로 고정 |
| 오른쪽 세로 점 목차 | 점 목차의 이름표를 날짜로 바꿔(2026.09 · 내돈내편…) 시간 순서가 보이게 함. 모바일은 점 대신 상단 띠(장 번호·이름·진행 막대) |
| 실적 숫자 구간, 마지막 한 문장 | "석 달의 기록"(4·4·1·2)과 "다음 장은 아직 쓰는 중입니다" |
| 스크롤 진입 시 나타남(GSAP ScrollTrigger) | IntersectionObserver + CSS transition |

일부러 안 가져온 것: 브랜드명·로고·문구, 3D 모델과 이미지, 코드, GSAP/Three.js(CDN 금지·용량), 수채 얼룩 배경 텍스처, Oswald/Roboto Condensed 조합(대신 Big Shoulders Display + IBM Plex Sans KR), 본문 오른쪽 정렬(한국어 긴 문장은 읽기 어려워 상세 구간은 왼쪽 정렬), 서비스·전문분야 6개 같은 회사 소개 구조.

## ② 페이지 구성 (시간 순)

1. **시작** `#top` — 이름, 한 줄 소개(기존 사이트 문장), 3줄 요약, "첫 장부터 읽기"
2. **프롤로그 · 춘천** `#prologue` — AI융합과 1학년, 자격증, 당근마켓 클론(시기 미확인이라 날짜 없이) + 자리표시
3. **1장 2026.09 내돈내편** — 제목 패널 → 상세(시연 영상, 설계·기능·기술, 해보기 접기, 링크·QR)
4. **2장 2026.10 Villagen** — 같은 구조, 가로 영상, 설치 안내는 접기
5. **3장 2026.11 Lolypoly**
6. **4장 2026.11 MARU**
7. **지금까지** `#tally` — 숫자 4개 + 기술과 쓴 프로젝트 목록
8. **5장 다음 장** `#next` — 인턴 구직, 이메일·GitHub (연락처 겸 마지막 문장)

각 장 = "장면 패널(첫인상)" + "상세 구간(읽는 곳)" 두 박자. 상세 구간은 반투명 검은 막을 깔아 점 형체 위에서도 읽힌다. 해보기 단계는 `<details>`로 접어 리듬을 유지.

## ③ 색·글꼴·모션

- 색(장별 배경 / 강조): 시작 `#0b0b0d`/`#d9d4ff`, 프롤로그 `#0e0f14`/`#cbd5ea`, 내돈내편 `#06201b`/`#7fe0c0`(초록=안전·돈), Villagen `#170f2c`/`#c6adff`, Lolypoly `#091831`/`#94c6ff`, MARU `#2b0f0c`/`#ffb48c`(단청 붉은색), 지금까지 `#121212`/`#e8e2d0`. 본문 `#f1efe9`, 보조 `#bdb9b0`. 모든 배경이 매우 어두워 본문·보조·강조 글자 모두 AA(4.5:1) 이상(계산상 최저는 보조 글자 대 MARU 배경 약 8:1).
- 글꼴: 영문 제목 Big Shoulders Display 800(압축 대문자), 한국어 제목·본문 IBM Plex Sans KR, 날짜·라벨 IBM Plex Mono. Google Fonts.
- 모션: 점 형체 모핑(입자마다 속도가 달라 흩어졌다 모임), 배경 색조 전환, 내용 아래→위 나타남, 탭이 안 보이면 애니메이션 정지. `prefers-reduced-motion: reduce`면 나타남·전환·흔들림을 끄고 형체는 움직임 없이 바로 그린다.
- 접근성: 건너뛰기 링크, `:focus-visible` 흰 외곽선+검은 테두리, 점 목차는 `aria-current`, 캔버스는 `aria-hidden`, 영상은 기존 `aria-label` 유지, 버튼·요약 높이 48px.

## ④ 자리표시 목록 (주상이 채울 것)

페이지에서 노란 점선 상자로 표시돼 있다.

1. 프롤로그: 왜 AI융합과에 왔는지, 입학 전에 무엇을 하고 있었는지 (2~3문장)
2. 내돈내편: 왜 고령층 금융·피싱 문제를 골랐는지, 처음 팀장을 맡으며 배운 것
3. Villagen: 대회 기간에 처음 겪은 일, 수상 발표 때 든 생각이나 배운 것
4. Lolypoly: 학교 정보를 찾으며 직접 불편했던 순간, 교수님 승인까지의 과정
5. MARU: 왜 외국인 여행자와 전통문화를 골랐는지, 앞의 세 장과 무엇이 달라졌는지
6. 다음 장: 인턴으로 어떤 팀에서 무엇을 배우고 싶은지
7. (선택) 당근마켓 클론 시기 — 알면 프롤로그나 별도 장으로 옮길 수 있음

## ⑤ 확인한 것 / 미확인

확인함 (Playwright, Chromium):
- 데스크톱 1440px·모바일 390px에서 가로 스크롤 없음(`scrollWidth === clientWidth`), 콘솔·페이지 오류 0건
- 장마다 배경색·점 형체·점 목차·상단 띠가 바뀌는 것 (`shots/*-00`~`-10`)
- reduced-motion 환경에서 `.motion` 클래스가 붙지 않고 숨은 요소 0개
- 첫 Tab에서 "본문으로 건너뛰기"에 포커스
- 참고 사이트: 안내대로 gsap·three를 로컬로 바꿔 끼워 1440/390으로 캡처. 섹션별 색조 패널, 오른쪽 정렬 제목, 점 목차, 별 파티클은 확인. **3D 점 형체 모핑은 이 환경(swiftshader) 캡처에선 보이지 않았다** — 부모 세션 설명에 따라 구현했고 실제 모습은 미확인.

미확인:
- 실제 휴대폰(iOS Safari 등)에서 캔버스 성능과 배터리 영향
- 영상 재생(캡처에선 포스터만 확인)
- 스크린리더 실제 낭독 순서
- 명도 대비는 색 값으로 계산했고 별도 도구 측정은 안 함
- 375px 기기 직접 캡처 없음(390px만)

캡처: `shots/desktop-*.png`, `shots/mobile-*.png` (장별 화면), `shots/*-full.png`(전체 페이지, 용량 때문에 절반 크기·256색으로 줄임; 고정 캔버스라 전체 캡처엔 점 형체가 맨 위에만 보임).

## ⑥ 장단점

- 장점: 프로젝트가 날짜 순 "장"으로 이어져 4개월 사이의 성장 흐름이 한눈에 읽히고, 장마다 색과 형체가 달라 기억에 남는다.
- 단점: 장면 패널마다 100vh를 써서 페이지가 길고(데스크톱 약 11,000px), 인사 담당자가 핵심(연락처·수상)까지 가려면 스크롤이 많이 필요하다.
