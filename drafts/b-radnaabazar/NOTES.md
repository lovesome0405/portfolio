# 시안 B: 지나온 길 (참고: radnaabazar.com/ko)

열어 보기: 저장소 루트에서 `python3 -m http.server` 후 `/drafts/b-radnaabazar/` 접속. 영상·QR은 `../../assets/`를 그대로 참조한다(기존 `index.html`, `style.css`, `assets/`는 수정하지 않음).

파일: `index.html`, `style.css`, `main.js`(바닐라 JS 약 60줄, 외부 스크립트 없음), `shots/`(캡처).

## ① 참고 사이트에서 가져온 원리

참고 사이트 분석 방법: Playwright로 1440px·390px에서 스크롤 캡처하고 DOM 계산 스타일을 뽑았다. CDN 차단 문제는 없었다(Next.js 자체 번들, 막힌 요청은 Cloudflare 분석 비콘 하나뿐).

| 참고 사이트에서 본 것 | 이 시안에서 | 
|---|---|
| "안녕하세요, 저는 / 이름" 두 단 인사 히어로 | **가져옴.** "안녕하세요, 저는 / 유주상입니다". 이름 일부만 색을 바꾸는 처리는 안 가져옴 |
| 히어로 아래 숫자 4개 줄(나이·경력·프로젝트 수) | **줄여서 가져옴.** 숫자를 크게 키우지 않고 작은 사실 줄(만든 서비스 4개, 수상 1회, 팀 4곳, 자격증)로 |
| "나의 여정 기록": 왼쪽에 연도가 `position: sticky; top:160px`로 따라오고, 세로선이 스크롤만큼 채워지는 타임라인 | **핵심으로 가져옴.** 이 시안의 뼈대. 왼쪽 월 숫자(09·10·11)가 붙어 따라오고, 세로선이 화면 45% 지점까지 채워지며, 도착한 구간의 숫자가 윤곽선에서 채운 글자로 바뀐다 |
| 화면 아래 떠 있는 알약 모양 메뉴(커리어/개인) | **바꿔서 가져옴.** 여정 구간에서만 나타나는 "지금 보는 곳" 표시 + 구간 바로가기(키보드로 이동 가능) |
| 마지막 "함께 이야기해요" 연락 영역 | **가져옴.** 여정의 다음 장으로 이어지는 문장("다음 장은 아직 비어 있습니다")으로 |
| 어두운 남보라 배경, JetBrains Mono 단일 글꼴, 형광 초록 강조 | **일부러 안 가져옴.** 복제처럼 보이고, 요즘 생성형 디자인의 흔한 기본값이기도 함 |
| 벤토 그리드 프로필, 원형 사진 링, 음악 플레이어, 다국어 인사 애니메이션, 경력 카드 | **안 가져옴.** 주상의 근거 자료(사진·경력)가 없고, 시간 순서 이야기라는 목표와 무관 |
| 프로젝트 카드 그리드 | **안 가져옴.** 프로젝트를 따로 모으지 않고 타임라인 안 각 시점에 넣어 "성장 순서"로 읽히게 함 |

이름, 문구, 이미지, 코드는 하나도 복사하지 않았다. 구조(인사 → 요약 → 여정 → 연락)와 스티키 날짜·진행선 모션 아이디어만 썼다.

## ⑤ 확인한 것 / 미확인

확인함 (Playwright, Chromium):
- 1440px·390px 모두 가로 스크롤 없음(`scrollWidth == clientWidth`), 콘솔 오류 없음
- Tab 순서: 건너뛰기 → 상단 메뉴 → 버튼 → 길 미리보기 링크 → 본문. 모든 초점에 3px 외곽선
- 감소 모션 설정에서 애니메이션 없음, 진행선 전부 채움, 모든 구간 도착 상태
- 색 대비: 위 표 수치(전부 AA 이상, 본문 텍스트 4.5:1 이상)
- 프로젝트 내용·링크·QR·영상은 모두 기존 `index.html`에서 옮김. 새 사실은 추가하지 않음

미확인:
- Safari·Firefox 실기기, 실제 휴대폰에서의 스크롤 성능과 `-webkit-text-stroke` 표현
- 스크린리더 실제 낭독(구조는 article/h3/dl로 짰지만 VoiceOver·NVDA로 들어 보지 않음)
- 외부 링크(배포 사이트·저장소)가 지금 열리는지
- 당근마켓 클론 시기, 자격증 취득 시기, 입학 시기
- 캡처: `shots/desktop-full.png`는 용량 때문에 50%로 줄였고, 모든 PNG는 256색으로 압축함

## ⑥ 장단점 한 줄씩

- 장점: 프로젝트가 "만든 순서"로 이어져, 석 달 동안 팀장 → 수상 → 실사용자 → 다국어 서비스로 넓어진 흐름이 스크롤 한 번에 읽힌다.
- 단점: 성장 이야기의 핵심인 "이때 배운 것"이 아직 전부 비어 있어, 주상이 채우기 전에는 기존 사이트보다 정보가 많지 않고 페이지가 길다(모바일 약 9,900px).
