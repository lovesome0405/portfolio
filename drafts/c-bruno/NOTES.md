# 시안 C · 성장 노선도 (참고: bruno-simon.com)

파일: `index.html`, `style.css`, `app.js`(바닐라 JS, 외부 스크립트 없음), 캡처는 `shots/`.
루트의 `index.html`, `style.css`, `assets/`는 건드리지 않았고 영상·이미지·QR은 `../../assets/...`로 참조한다.

## ① 참고 사이트에서 가져온 원리

2026-11-24에 Playwright(Chromium + SwiftShader WebGL)로 1440px, 390px에서 열어 봤다. 확인한 흐름은 이렇다. 로딩 중에는 링이 차오르고, 다 차면 바닥 위 원형 섬과 "Click to Start" 표시가 나온다. 시작하면 차를 몰고 다니고, Esc를 누르면 소개, 조작법, 업적, 소리 같은 메뉴 창이 뜬다. 첫 화면에서 DOM으로 읽을 수 있는 글은 없었고, 정보는 모두 캔버스 안에 있다.

| 가져온 것 | 이 시안에서 바꾼 형태 |
|---|---|
| 직접 움직여서 정보를 발견하는 경험 | 열차 표시를 움직여 역(프로젝트)에 닿으면 승강장 패널이 열린다 |
| 카메라가 주인공을 따라감 | 지도가 열차를 따라 가로로 흐르고, 앞으로 갈 길이 더 보이게 열차를 화면 42% 지점에 둔다 |
| 키보드, 마우스, 터치를 모두 지원 | ←/→/Home/End, 지도 끌기, 트랙패드 가로 스크롤, ◀▶ 버튼, 역 이름 누르기 |
| 조작 안내를 띄웠다가 숨김 | 지도 위 안내 문구가 첫 이동 2.5초 뒤 사라진다 |
| 업적처럼 수집하는 재미 | "방문 n/6" 계기판, 아직 안 간 역에 빨간 점 |
| 월드 안의 오브젝트가 곧 메뉴 | 역 표지판이 곧 프로젝트 링크 |

**일부러 가져오지 않은 것**
- 3D, WebGL, 물리 엔진, 차량, 섬과 나무 오브젝트, 사운드, 네온 격자 색감, 문구와 이름, 코드. 아이디어와 상호작용 원리만 참고했다.
- 로딩 화면과 "클릭해서 시작" 단계. 채용 담당자가 기다리게 되므로 첫 화면부터 내용이 보이게 했다.
- 캔버스 안에만 있는 정보. 이 시안은 모든 글이 HTML이라 스크린리더와 검색에서 읽힌다.

**3D를 쓰지 않은 이유**: SwiftShader 기준으로 참고 사이트는 의미 있는 첫 화면까지 수십 초가 걸렸다(소프트웨어 렌더링이라 실기기보다 느린 수치다). 이 시안의 메타포(노선을 따라가는 한 줄 여정)는 2D로도 충분하다. 3D를 빼면 저사양 휴대폰, 키보드 사용자, 스크린리더 사용자를 함께 지킬 수 있다. 그래서 SVG와 CSS transform으로 같은 탐색 감각을 냈다.

## ② 페이지 구성과 탐색 메타포

**메타포: 성장 노선도.** 춘천에서 출발한 열차 노선에 프로젝트 하나가 역 하나다. 지도 바탕의 세로 띠는 달(입학 이후, 9월, 10월, 11월, 겨울방학)을 나타내서, 가로 위치가 곧 시간이다. 지나온 선로는 진한 청록, 아직 안 간 선로는 옅은 색, MARU 다음 "인턴" 구간은 점선(아직 놓이지 않은 선로)이다. 출발역 주변 호수는 춘천을 가리키는 장식이다.

위에서 아래 순서:
1. **상단 막대**: 이름, `목록으로 보기`, `연락하기`
2. **소개 한 줄과 노선 안내판**: 6칸(출발, 09 내돈내편, 10 Villagen, 11 Lolypoly, 11 MARU, 다음 인턴). 첫 화면에서 지도를 만지지 않아도 프로젝트 4개 이름과 시기가 보인다. 누르면 지도가 그 역으로 간다.
3. **지도**(모바일 46svh, 데스크톱은 남은 높이)와 **승강장 패널**(데스크톱은 오른쪽 380px, 모바일은 지도 아래): 시기, 한 줄 설명, 역할, 기술, 결과, 화면 썸네일, 자리표시, `자세히 ↓`, 외부 링크
4. **목록으로 보기(#list)**: 요약표 4줄, 그 아래 역별 상세(영상, 사실, 직접 해보기 단계, QR, 링크)를 세로 선로 모양으로 잇는다. 마지막은 "다음 역: 인턴"과 기술 목록, 연락처.

**30초 경로**: 첫 화면의 안내판이나 `목록으로 보기`에서 요약표 4줄까지 한 번에 간다. JS가 꺼져 있으면 지도(`.stage[hidden]`)는 숨겨지고 목록만 남는다(확인함).

## ③ 색·글꼴·모션·조작 결정

- **색**: 지도 종이(#f3efe6) 위에 짙은 남색 글자(#1b2330), 선로는 청록(#0d6670), 열차와 수상 표시는 주홍(#b23a26). 자리표시는 노란 바탕에 점선 테두리라 한눈에 띈다. 다크 모드는 넣지 않았다(종이 지도 콘셉트를 우선).
- **대비(WCAG AA, 계산값)**: 본문 13.8:1, 보조 글자 6.6:1, 청록 글자 5.8~6.3:1, 수상 배지 흰 글자 6.0:1, 자리표시 11.5:1, 지도 띠 라벨 최저 4.95:1. 모두 4.5:1 이상이다.
- **글꼴**: IBM Plex Sans KR(본문, 제목)과 IBM Plex Mono(시기, 역 번호. 교통 안내판 느낌). Google Fonts를 쓴다.
- **모션**: 열차는 거리에 비례해 감속하며 도착하고, 카메라는 0.18 비율로 따라간다. `prefers-reduced-motion: reduce`면 열차와 카메라가 즉시 이동하고 CSS 전환과 부드러운 스크롤도 끈다(즉시 이동 확인함).
- **조작**: 지도는 `tabindex=0`인 그룹이라 포커스 후 ←/→로 움직인다. 역 표지판은 실제 `<button>`(44px 이상)이고, Tab으로 포커스하면 그 역으로 간다. 터치는 `touch-action: pan-y`라서 세로 스크롤은 그대로 되고 가로로 끌 때만 달린다. 도착한 역 정보는 `aria-live="polite"` 패널로 읽힌다. 포커스 표시는 파란 3px 외곽선이다.
- **캡처용 매개변수**: `?station=2`로 열면 해당 역에서 시작한다.

## ④ 자리표시 목록 (주상이 채울 것)

화면에는 노란 상자 `[주상이 채울 부분: …]`로 보인다.

| 위치 | 채울 내용 |
|---|---|
| 목록 › 출발역 본문 | 왜 AI융합과에 왔는지, 입학 전에 무엇을 하고 있었는지 |
| 목록 › 출발역 › 짐 칸 | ADsP, 리눅스마스터 2급, 당근마켓 클론을 한 시기(알면 노선 위 역으로 옮길 수 있음) |
| 목록 › 내돈내편 끝 | 이 역에서 배운 것(예: 처음 팀장을 맡으며 달라진 점) |
| 목록 › Villagen 끝 | 이 역에서 배운 것(예: 첫 수상에서 무엇이 통했다고 느꼈는지) |
| 목록 › Lolypoly 끝 | 이 역에서 배운 것(예: 우리 학교 사람들을 위해 만들며 달라진 점) |
| 목록 › MARU 끝 | 이 역에서 배운 것(예: 석 달간 네 프로젝트를 거치며 생긴 작업 방식) |
| 목록 › 다음 역 | 인턴에서 해 보고 싶은 일, 가고 싶은 방향 |
| 지도 승강장 패널 6곳 | 위와 같은 짧은 버전(`app.js`의 `STATIONS[].fill`) |

추정이 들어간 표기도 하나 있다. 출발역의 "2026"은 "2026년 11월 현재 1학년"에서 추정한 입학 연도다. 정확한 입학 시기로 바꿔야 한다.

## ⑤ 확인한 것과 미확인 항목

**확인함(Playwright, headless Chromium)**
- 1440px, 390px 모두 가로 스크롤 없음(`scrollWidth`가 화면 너비와 같음), 페이지 오류 0건
- 마우스로 지도를 끌면 가까운 역에 맞춰 멈춤, 역 버튼 클릭, 안내판 링크 + Enter, ◀▶ 탭, 터치 끌기(CDP 터치 이벤트) 모두 패널이 맞게 바뀜
- 터치 끌기 버그 하나를 찾아 고쳤다. 처음 닿은 svg에서 넘어온 `lostpointercapture`가 끌기를 바로 끝내던 문제였다.
- reduced-motion에서 즉시 이동, JS를 끄면 목록만 표시
- 캡처 6장: `shots/{desktop-1440,mobile-390}-{1-first,2-explore,3-list}.png`

**미확인**
- 실제 iOS Safari와 Android Chrome에서의 끌기 감각, 관성, 세로 스크롤과의 충돌. 에뮬레이션으로만 봤다.
- 실기기 성능(저사양 폰 프레임). 다만 SVG 하나와 transform만 쓰는 구조다.
- 스크린리더(VoiceOver, TalkBack) 실제 낭독 순서와 `aria-roledescription` 표현
- 참고 사이트: `www.googletagmanager.com`이 프록시에서 막혔지만 분석용이라 화면에는 영향 없음. 소리, 게임패드, 업적 상세는 직접 확인하지 않았다. 헤드리스 SwiftShader라 실제 로딩 시간은 재지 못했다.
- 시안 C 페이지에서 Google Fonts 로딩은 `file://` 캡처 환경에서 확인하지 않았다. 캡처에 보이는 글꼴은 대체 글꼴일 수 있다.

## ⑥ 이 시안의 장단점

- **장점**: 프로젝트가 시간 순서대로 이어지는 성장 이야기가 지도의 가로축 하나로 바로 읽히고, 직접 움직이는 재미가 있으면서 첫 화면 안내판과 목록으로 30초 안에 4개를 다 볼 수 있다.
- **단점**: 지도와 목록에 같은 내용이 두 번 있어 관리할 곳이 두 군데(`app.js` STATIONS, `index.html` 목록)이고, 데스크톱에서 승강장 패널 아래 빈 공간이 생긴다.
